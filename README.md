# 이키즈라이브 번역 아카이브

`messages.db`의 멤버별 번역을 월별로 볼 수 있는 정적 사이트입니다.

## 실행

```sh
python3 scripts/export_data.py
python3 -m http.server 5173 --directory dist
```

http://localhost:5173 에서 확인합니다. DB 갱신 후 export 명령을 다시 실행하세요.

- 한국 시간(UTC+9) 기준 실제 게시일로 월을 분류합니다. 게시일은 X snowflake ID에서 계산하며 DB의 수집 시각과 구분합니다.
- `corrected_text`가 있으면 수정 번역을 우선합니다.
- 월별 탐색, 멤버 필터, 전체 기간 검색, 이름/계정/번역/원문 검색, 정렬, 원문 펼치기, 첨부 이미지, 원문 링크를 제공합니다.
- URL에 월, 멤버와 검색 조건을 보존합니다. 한 번에 20개씩 표시합니다.
- 원본 DB와 Discord 메시지/채널 ID는 배포하지 않습니다. 번역 데이터는 `dist/data.json`에 내보냅니다.
- 첨부 이미지는 원본 외부 URL을 사용하며 삭제 또는 접근 제한 시 열기 링크로 표시합니다.
- 자동 DB 동기화는 없습니다. 새 자료 반영에는 재내보내기와 재배포가 필요합니다.

## 프로필 사진

DB의 `twitter_handle`과 `character_name`을 기준으로 매칭합니다. 계정별 X 프로필 이미지를 [Unavatar](https://unavatar.io)로 가져와 `dist/avatars/`에 저장했습니다. 계정 매핑과 이미지 출처는 `scripts/avatar_sources.json`에 기록합니다. 이름은 [공식 멤버 소개](https://www.lovelive-anime.jp/lovehigh/member/?m=2)를 참고한 한국어 표기입니다. 사진은 저장 시점의 스냅샷이며 자동 갱신되지 않습니다. 새 계정 추가 시 매핑과 이미지를 함께 추가하세요.

DB에 `media_urls` 열이 없어도 내보낼 수 있습니다. 첨부 이미지 정보가 없는 DB에서는 게시물 이미지를 표시하지 않습니다.

## 시간순으로 이어 읽기

기본 화면은 가장 오래된 달부터 시작하는 한 줄 타임라인입니다. 모든 멤버의 글을 실제 게시 시간순으로 섞고 날짜 구분선을 표시합니다. 같은 시각의 글은 X 게시물 ID로 순서를 확정합니다. 20개씩 더 펼칠 때 기존 카드와 열린 원문을 유지하며 새 기록의 시작으로 이동합니다. 월의 마지막 기록을 펼치면 다음 기록이 있는 달로 이어 읽을 수 있습니다. 연도를 넘어 이동하며 DB에 글이 없는 달은 건너뜁니다. 멤버/검색 조건을 유지하고, 최신순에서는 반대 방향으로 이어갑니다. 전체 기간을 선택하면 월을 넘겨 한 타임라인에서 읽을 수 있습니다. `처음부터 읽기`는 필터를 초기화하고 모든 멤버의 첫 기록으로 돌아갑니다.

## 캘린더와 보기 단위

X 스타일의 한 열 피드에서 `월별`, `일별`, `전체 기록` 탭으로 범위를 전환합니다. 캘린더 날짜를 누르거나 날짜 입력을 바꾸면 하루의 타임라인으로 이동하고, `이 달 전체 보기`는 캘린더의 월로 이동합니다. 월 입력으로 연도와 월을 직접 선택할 수도 있습니다. 캘린더 좌우 버튼은 탐색 중인 달만 바꾸며, 기록이 없는 날짜도 선택해 빈 화면을 확인할 수 있습니다. 날짜별 글 수는 선택한 멤버를 기준으로 계산합니다. 캘린더에서 방향키로 날짜 간 이동이 가능합니다.

일별 이어 읽기는 다음 기록이 있는 날로, 월별 이어 읽기는 다음 기록이 있는 달로 이동합니다. 상단의 이전/다음 버튼은 달력의 실제 하루/한 달씩 이동하므로 기록이 없는 기간도 확인할 수 있습니다. 모바일에서는 상단 `캘린더` 버튼으로 달력을 펼칩니다. 날짜/보기 단위를 URL에 보존하고, 게시물의 `링크 복사`는 해당 날짜와 게시물 위치를 포함한 링크를 복사합니다. 좋아요/답글 수는 원본 DB에 없으므로 표시하지 않습니다.

## 프로필로 멤버 선택

멤버 필터는 `전체` 버튼과 10명의 프로필 사진으로 제공합니다. 선택 상태는 테두리와 이름 색상, `aria-pressed`로 표시합니다. 월별/일별/전체 기록 범위와 검색·정렬을 유지한 채 선택한 멤버의 글과 캘린더의 글 수를 함께 갱신합니다. 전체 버튼은 멤버 필터만 해제하며, 기존 `member` URL도 그대로 복원합니다. 모바일에서는 두 줄로 모든 멤버를 표시합니다.

## 이키즈라이브 색상

[프로젝트 공식 비주얼과 클럽 로고](https://digitalpr.jp/r/109574)의 블루·오렌지를 참고한 기본 테마입니다. 10명의 저장된 X 프로필 배경색을 프로필 테두리, 이름 옆 포인트, 상단 색상 띠에 반영했습니다. 멤버를 선택하면 탭·월 표시·캘린더·이어 읽기 버튼이 해당 멤버 색을 따라가고, 전체 선택은 기본 블루로 복귀합니다. 흰색은 회색 테두리로 구분합니다. 팔레트 출처와 샘플 값은 `scripts/palette_sources.json`에 기록했으며, 공식 디자인 시스템의 지정 HEX라고 주장하지 않습니다. 밝은 색의 글자·버튼은 읽기 쉬운 어두운 색을 사용합니다.

## Bootstrap 레이아웃

[Bootstrap 5.3.8](https://getbootstrap.com/docs/5.3/getting-started/introduction/)의 실제 12열 그리드, 폼, 버튼, 내비게이션 클래스와 Offcanvas를 사용합니다. 1200px 이상은 사이드바/피드/캘린더 3열, 768~1199px은 간결한 사이드바와 피드 2열, 작은 화면은 한 열입니다. 1200px 미만에서 캘린더는 포커스 관리·Esc·배경 닫기를 지원하는 Bootstrap 패널로 열립니다. 날짜를 선택하면 패널을 닫고 피드의 날짜 제목에 포커스를 돌려줍니다. 프레임워크 파일은 공식 배포본의 SHA-384를 검증한 뒤 `dist/vendor/bootstrap/`에 저장해 사용하며 MIT 라이선스를 함께 보존했습니다.
